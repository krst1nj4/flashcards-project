# flashcards-project
A handheld language flashcard device built on Raspberry Pi Zero W  with a 3.5" SPI display. Features a Leitner spaced repetition algorithm  that prioritizes cards you struggle with. Supports multiple languages  (German &amp; French). Built as an OS course project to demonstrate  file I/O, process management, and hardware communication via SPI protocol.

# Flashcards RPi

App for learning foreign languages on Raspberry Pi Zero W.

## Technologies
- Raspberry Pi Zero W
- Python 3
- Waveshare 3.5" SPI displej

## Languages
- German
- French (soon)

## Booting
```bash
python3 main.py
```

## How does it work?
Leitner algorithm — cards you dont know show up more frequently.
